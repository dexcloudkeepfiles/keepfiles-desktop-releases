# KeepFiles Desktop — releases

Windows-приложение для автоматической загрузки выбранной папки в KeepFiles и ручного скачивания файлов и папок из облака.

Этот репозиторий содержит установщики и описания выпусков. Исходный код приложения здесь не публикуется.

## Скачать

Откройте [Releases](https://github.com/dexcloudkeepfiles/keepfiles-desktop-releases/releases) и выберите нужную версию. Предварительные сборки помечены Pre-release.

Для установки используйте файл `KeepFilesDesktop-<версия>-Setup.exe`. Рядом опубликована контрольная сумма SHA-256 для проверки целостности загрузки. Она не заменяет цифровую подпись издателя.

## Текущие ограничения

- Сборка 0.3.2 предварительная; установщик не подписан сертификатом Windows.
- Автообновления программы пока нет: установка новых версий выполняется вручную. Перед обновлением завершите приложение через меню системного трея.
- Имена файлов и папок сохраняются точно. Конфликтующие файлы не перезаписываются автоматически.
- Полноценная двусторонняя синхронизация, распространение удалений и история версий ещё не реализованы.

Не размещайте в публичных обращениях токены доступа, пароли, закрытые ключи и содержимое личных файлов.
